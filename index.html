دليل رفع مشاريعك إلى GitHub

أدخل اسم المستودع واسم حسابك، وسنجهّز لك الأوامر والروابط لتنسخها مباشرة.

⚙️ بيانات المشروع

اكتب الاسم كما يظهر تماماً في GitHub، من دون رابط المستودع.
تجده في رابط ملفك الشخصي: github.com/username
اتركه فارغاً إذا كنت ستنفّذ الأوامر من داخل مجلد المشروع بالفعل.
ننصح باستخدام main كما هو شائع في GitHub.

🚀 أول رفع للمشروع

مرة واحدة لكل مستودع محلي

هذه الأوامر مناسبة عندما يكون لديك مجلد مشروع محلي ومستودع GitHub جديد وفارغ. افتح CMD أو Terminal داخل مجلد المشروع ثم نفّذها بالترتيب.


 
فتح المستودع على GitHub ↗إنشاء مستودع جديد ↗

 
عند إنشاء المستودع على GitHub، إذا كنت ستستخدم هذه الأوامر لأول مرة، اترك خيارات Add a README وAdd .gitignore وChoose a license غير محددة، حتى يكون المستودع فارغاً وتتجنب تعارض أول رفع.






 
🔁 رفع التعديلات مستقبلاً

 
بعد أن يكون المشروع مربوطاً بالمستودع، لا تحتاج إلى تكرار git init أو git remote add. استخدم هذه الأوامر كلما عدّلت الملفات وأردت نشر التعديلات:

 

 
غيّر رسالة Commit لتصف التعديل الحقيقي، مثل: Add search feature أو Fix login bug أو Update README.






 
🧭 إذا كان المستودع على GitHub يحتوي ملفات مسبقاً

 
إذا أنشأت المستودع مع README أو أي ملف آخر ورفض Git عملية Push برسالة fetch first، اسحب التغييرات أولاً ثم ارفع مشروعك:

 

 
لا تستخدم git push --force كحل سريع؛ فقد يؤدي إلى استبدال تاريخ أو تغييرات موجودة على GitHub. إذا ظهر Merge Conflict، افحص git status وعالج الملفات المتعارضة قبل إكمال الدمج.






 
📘 إنشاء ملف README.md

 
أنشئ ملفاً باسم README.md داخل مجلد المشروع. هذا قالب أولي يمكنك تعديله ليشرح مشروعك للزوار:

 






 
🧹 ملف .gitignore المقترح

 
أنشئ ملفاً باسم .gitignore في جذر المشروع. يمنع إضافة ملفات مؤقتة وشائعة إلى Git:

 

 
لا ترفع كلمات المرور أو مفاتيح الخدمات السرية أو ملفات إعدادات خاصة. إذا سبق أن أضفت سراً إلى Commit، فإن حذفه من الملف وحده لا يزيله من تاريخ Git؛ غيّر السر المتسرب واتبع خطوات تنظيف التاريخ عند الحاجة.






 
🌐 نشر الموقع باستخدام GitHub Pages

 
1
افتح المستودع ثم ادخل إلى Settings → Pages.

 
2
من قسم Build and deployment اختر Deploy from a branch.

 
3
اختر الفرع main والمجلد /(root) ثم اضغط Save.

 
4
بعد انتهاء النشر سيكون رابط الموقع عادةً:

 

 فتح إعدادات Pages ↗
 
قد يستغرق ظهور الموقع بضع دقائق. يجب أن يكون ملف الصفحة الرئيسية باسم index.html في جذر المستودع أو في مجلد النشر المختار.






 
🛠️ أوامر Git المفيدة عند الحاجة

 
معرفة حالة الملفات والتغييرات
git status

 
عرض سجل الـ Commits
git log --oneline --graph --decorate

 
معرفة المستودع البعيد المرتبط

 
تغيير رابط المستودع البعيد إذا كان خاطئاً

 
إلغاء إضافة ملف إلى Staging قبل Commit
git restore --staged FILE_NAME

✅ قائمة تحقق قبل الرفع

 
    
  
  • تأكد أنك داخل مجلد المشروع الصحيح.
    • 
  
  • اختبر المشروع محلياً قبل رفعه.
    • 
  
  • لا ترفع كلمات مرور أو ملفات تحتوي بيانات سرية.
    • 
  
  • تأكد من اسم المستودع ورابط GitHub.
    • 
  
  • اكتب README يشرح فكرة المشروع وطريقة تشغيله.
    • 
  
  • استخدم .gitignore المناسب للغة والأدوات المستخدمة.
    • 
  
  • بعد الرفع، افتح المستودع وتأكد من ظهور الملفات.
    •
